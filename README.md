# UFS — Experimental Filesystem

UFS is an experimental cross-platform filesystem project. It is not production-ready; encryption support is disabled pending a correct, audited implementation.

## Status

- Zig 0.13 project; full compiler/build verification is still pending.
- Static and script checks are documented in `REMEDIATION_NOTES.md`.
- Do not use with important data.

See `BUILD_README.md` and `docs/` for project details.
